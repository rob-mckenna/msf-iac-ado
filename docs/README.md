# Documentation

This repository uses the `docs\` folder as the primary home for architecture and implementation guidance.

## Structure

- `adr\` - Architecture Decision Records (ADRs) that capture key technical and platform decisions.
- `architecture\` - Architecture guides, overviews, and diagrams for the platform.
- `guides\` - How-to and onboarding documentation for operators and contributors.

## Recommended Reading Order

1. Start with `architecture\overview.md` for the platform view.
2. Review the ADRs in `adr\` to understand why the platform is designed this way.
3. Use the documents in `guides\` for setup, deployment, and onboarding tasks.
